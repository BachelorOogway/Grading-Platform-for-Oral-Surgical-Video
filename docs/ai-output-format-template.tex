\section{Hard formatting rules}
\label{sec:rules}

\begin{enumerate}[leftmargin=*]
  \item Four section headers \textbf{must} appear, in order:
        \texttt{Level 1 Analysis}, \texttt{Level 2 Analysis},
        \texttt{Level 3 Analysis}, \texttt{Level 4 Analysis}.
  \item Every required field must be non-empty (upload rejects incomplete parses).
  \item Level~2 phases: one line each, shape
        \texttt{[HH:MM:SS to HH:MM:SS] - <description>}.
  \item Totals must be integers and match list lengths:
        structures, instruments, phases.
  \item Level~3: after \texttt{Is the surgery completed?} answer exactly
        \texttt{Yes} or \texttt{No}.
  \item Level~4: six dimensions, each starting on its own line as
        \texttt{<Canonical Title>: <1-5> - <justification>}.
        Justification must not be empty. Score must be a single digit 1--5.
  \item Keep human-evaluation markers
        (\texttt{[Human Expert Evaluation:\ldots]}) after each AI field;
        they are for experts and must not replace AI values.
  \item Do \textbf{not} rename canonical Level~4 titles if those titles are
        available (see Table~\ref{tab:l4}).
\end{enumerate}

\section{Prompt snippet for the LLM}
\label{sec:prompt}

Copy the following into the system or user prompt:

\begin{lstlisting}[style=aiout]
Output MUST follow the grading-platform template exactly.
- Keep all section headers and field labels unchanged.
- Prefer canonical Level 4 titles from the template.
- Every required field must be non-empty.
- Level 2 phases: "[HH:MM:SS to HH:MM:SS] - description" on one line;
  include "Total number of detected phases: <P>".
- Level 3: answer "Is the surgery completed?" with Yes or No;
  include Next Action Prediction and Clinical Rationale.
- Level 4: include ALL six dimensions as
  "Label: <1-5> - <justification>".
Do not invent alternate Level 4 titles if the canonical ones are available.
Fill the template below; replace only the <placeholders>.
\end{lstlisting}
